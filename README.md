# KisanSathi AI 🌾

An AI-powered agricultural assistant for crop leaf disease detection and Urdu audio remedies advisory.

## Project Structure

```
KisanSathi_AI/
├── assets/
│   ├── sample_leaves/
│   └── audio_outputs/
├── data/
│   └── remedies_urdu.json
├── utils/
│   ├── __init__.py
│   ├── disease_detector.py
│   └── tts_engine.py
├── .streamlit/
│   └── config.toml
├── app.py
├── requirements.txt
└── README.md
```

## Setup Instructions

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   streamlit run app.py
   ```
